Module 1 — Foundation
Taste Map
Universal preference engine. 70 anchors across music, visual, writing, teaching, class energy. 5 voice references (Brady, Wicks, Cus, Carlton, Miyagi). Every module queries it.
/taste/taste status/taste music/taste visual/taste voices
Feeds → Reed, DJ Curator, Sound Studio, Content Conductor, Student Intelligence
LIVE
Module 2 — Meta Layer
Architect
Intent → structured plans. Scans PM2 (16 services), vault (35 projects), 6 agents. Outputs JSON + Mermaid + interactive HTML. Grounds every plan in Cathedral infrastructure.
/architect <intent>/architect status
Feeds → All future builds. Templates: agent-build, content-series, hardware-integration
LIVE
Module 3 — Audio/Class
DJ Curator
Boxing class playlists from taste map. Energy curves: arrival → warmup → technique → combos → burnout → cooldown. 5 profiles: standard, la_habana, old_school, war_mode, wildcard_heavy.
/playlist/playlist la_habana/playlist rate 5/playlist vibe aggressive
Consumes ← Taste Map. Feeds → Content Conductor (playlist links)
LIVE
Module 4 — Audio/Media
Sound Studio
Transcription (local Whisper, Metal GPU), voice (Edge TTS), clone voice (Chatterbox), instrumentals (Replicate MusicGen), podcast (DeepSeek script → two-voice audio).
/sound voice/sound clone/sound transcribe/sound instrumental/sound podcast
Feeds → Content Conductor (voiceovers, beats). Consumes ← Taste Map (voice pattern)
LIVE
Module 5 — Vision
Gym Eyes
YOLO pose estimation (Metal GPU) → punch detection → combo detection → technique scoring (0-100) vs canonical Cuban form. Guard return, stance width, velocity analysis. Auto coaching notes.
/eyes/eyes analyze/eyes last
Feeds → Student Intelligence (technique scores), Content Conductor (highlight clips)
LIVE
Module 6 — Orchestration
Content Conductor
Coordinates Reed + Sound Studio + DJ Curator + Kit GM into content pipelines. 5 templates. Caption generator uses taste map voice profile. Approval queue on Telegram. Replaces social media manager.
/content/content ideas/content caption/content queue/content approve
Consumes ← ALL modules. Target: 2-3 posts/week
LIVE
Module 7 — Coaching
Student Intelligence
Per-student profiles for all 72 members. Attendance, technique scores, combos, coaching notes. Churn prediction (red/yellow/green). Personalized drill recommendations. PunchPass CSV import.
/student John/student John focus/student John note/students risk/students improving
Consumes ← Gym Eyes, Boxing Engine, PunchPass. Future: student-facing portal
LIVE
Module 8 — External Intelligence
Community Radar
Autonomous scanning: Reddit (boxing + AI subs), HackerNews, GitHub trending. Signal filters: peer validation, explanatory depth, novelty, cross-domain bridging. Voice registry tracks consistent posters.
/radar/radar run/radar voices/radar <topic>
Feeds → Predictive Graph (new knowledge), Content Conductor (external content to share)
LIVE
