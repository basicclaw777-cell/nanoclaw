Channel Brief
The Cathedral's knowledge graph — connections between vault nuggets across all domains. Finds what the flat file structure hides. The vault holds thousands of notes in Obsidian, but the real value is in the connections between them. Vault Graph maps these connections, finds orphan nodes, and surfaces convergence patterns that feed Gold Extraction.
Potential Missions
Nugget Clustering
Embed all vault nuggets and cluster by semantic similarity. Find natural groupings that don't match the folder structure — the hidden taxonomy.
Gain: Emergent topic clusters the folder structure obscures
Cross-Domain Link Discovery
Find nuggets in different domains that reference the same concept, ratio, or pattern. The sacred geometry note that echoes the Tesla patent — without citing it.
Gain: Hidden convergences across independent research lines
Orphan Node Detection
Find vault notes with no incoming or outgoing links. These are either dead ends or missing connections — both worth knowing about.
Gain: Connection gaps and abandoned research threads
Convergence Pathway Mapping
For any two vault topics, find the shortest path of connections between them. Reveals how domains relate through intermediate concepts.
Gain: Relationship chains between any two research areas
Knowledge Density Analysis
Map which vault areas are densely interconnected (mature understanding) vs sparsely linked (early research). Shows where depth exists and where it's thin.
Gain: Research maturity map across all Cathedral domains
