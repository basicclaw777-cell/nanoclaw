WhatsApp Agent

Basic Reflex — AI-powered inbound messaging

Setup Required

  1. Create a Meta Business Account at business.facebook.com
  2. Set up WhatsApp Business API in Meta Developer portal
  3. Get your Phone Number ID and Permanent Token
  4. Add to ~/nanoclaw/.env:
    WHATSAPP_TOKEN=your_token
    WHATSAPP_PHONE_ID=your_phone_id
  5. Set webhook URL to https://your-domain/wa/webhook
  6. Use Cloudflare Tunnel: cloudflared tunnel --url http://localhost:8080
